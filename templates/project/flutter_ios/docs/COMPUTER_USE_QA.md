# Computer Use QA

Use only when explicitly requested.

## Prep

- Confirm simulator device and OS.
- Build/install app.
- Launch app and capture screenshot evidence.

## Matrix

- First launch.
- Navigation.
- Main workflows.
- Error/empty states.
- Accessibility labels.
- IAP purchase/restore if applicable.

## Exit

Create bug cards for failures. Do not claim absolute bug-free. Record unresolved work only when present; otherwise NEXT_ACTION=NONE.
